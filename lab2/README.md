## Как пересобрать всё с нуля

Окружение — общий venv лабораторных `karpenka_labs/.venv`
(Python 3.14; `gemmi`, `numpy`, `matplotlib`, `requests`, `openpyxl`):

```
cd lab2
curl -o structures/2hyy.cif https://files.rcsb.org/download/2HYY.cif
curl -o structures/3qrj.cif https://files.rcsb.org/download/3QRJ.cif

..\.venv\Scripts\python.exe scripts\prepare_structures.py   # анализ + 6 рабочих файлов
..\.venv\Scripts\python.exe scripts\superpose.py            # наложение, RMSD
..\.venv\Scripts\python.exe scripts\make_figures.py         # иллюстрации

cd report && pdflatex report.tex && pdflatex report.tex
cd ..\guide && pdflatex guide.tex && pdflatex guide.tex
```

`prepare_structures.py` читает `lab1/data/uniprot_P00519.json` — папка `lab1` должна лежать рядом.
pdflatex запускается дважды (со второго прохода подставляются оглавление и ссылки).

## Про ChimeraX

Задание сформулировано в командах UCSF ChimeraX, но на этой машине он не установлен
(в PyPI его нет — это отдельное настольное приложение со своим интерпретатором).
Все операции выполнены программно через `gemmi`, а в отчёте для каждого пункта приведена
эквивалентная команда ChimeraX; полный сценарий — в конце гайда (раздел «Как повторить всё с нуля»).
Числа получены из реальных координат, иллюстрации построены по тем же координатам.

## Ключевые результаты

- Нумерация обеих структур совпадает с UniProt P00519: **сдвиг 0** (совпадение 100 % и 99,6 %).
  Единственное несовпадение в 3QRJ — сам остаток 315 (`T` → `I`), то есть других мутаций нет.
- Остаток 315 найден в координатах: **THR315** в 2HYY, **ILE315** в 3QRJ.
- Пропуски: 275 (1 остаток) в 2HYY, 274–278 (5 остатков) в 3QRJ — оба в поверхностной петле,
  **сайт связывания разрешён полностью** (25 и 27 контактных остатков).
- Лиганды: `STI` (иматиниб, 37 атомов) и `919` (ребастиниб, 41 атом). Остаток 315 входит
  в список контактов в обеих структурах.
- Наложение: **RMSD 0,815 Å по 242 парам** после итеративного отбрасывания
  (1,292 Å по всем 257 парам). RMSD в киназном домене 1,301 Å.
- Отклонение Cα остатка 315 — **0,386 Å**, меньше среднего по структуре.
- Наибольшие расхождения (до 7,95 Å) — остатки 389–400, то есть **петля активации** 381–405;
  вызваны в первую очередь разными связанными лигандами, а не мутацией.

**Главный вывод:** глобальное RMSD не доказывает идентичность сайта связывания — оно усредняет
по сотням остатков и считается по Cα, тогда как мутация меняет боковую цепь.
